# Automated Review Rating System

## 📌 Overview
The Automated Review Rating System predicts numerical ratings (e.g., 1–5 stars) for user reviews automatically.
It leverages Natural Language Processing (NLP) and Machine Learning/Deep Learning techniques to analyze the sentiment and meaning of reviews, providing consistent and unbiased rating predictions.

## 🚀 Features
Automatically predicts ratings based on review text.

Uses NLP preprocessing: tokenization, stopword removal, stemming/lemmatization.

Implements LSTM , Bidirectional LSTM ,Distil-BERT deep learning models.

Supports evaluation with accuracy, precision, recall, and F1-score.

Visualizes performance with confusion matrices and classification reports.

Provides an interactive UI via Streamlit & another made in flask.
